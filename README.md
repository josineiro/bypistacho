# PISTACHO — bypistacho.com

La web de PISTACHO, productora de cine publicitario y contenido (Buenos Aires).

Es un sitio estático: todo lo que se publica está en `sitio/` y Vercel lo sirve tal cual, sin compilar nada (ver `vercel.json`).
Las páginas se generan fuera de este repositorio; acá sólo se sube el resultado.

- Los comerciales enteros van partidos en tramos (`media/full-*-p1.mp4`, `-p2`…) y la página los vuelve a unir al reproducirlos.
- La landing anterior (React + Vite, febrero 2026) quedó en la rama `landing-2026`.
